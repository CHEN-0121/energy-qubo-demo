    [ MOTIVATION ]

    非核、低碳之下，每種電源該發多少？

    台灣正走向非核、低碳的電力系統，每年都要決定各種電源發多少電。

    這份配置要同時兼顧成本、碳排和供電穩定，三者互相拉扯：燃煤便宜，但碳排高；再生能源乾淨，但出力不穩定。

    發電量只能一格一格地選（八種電源各選一格就有約 5.1 億種組合），再加上很多政策限制，傳統的混合整數規劃在這種規模下很難擴展。

    所以我們把它寫成 QUBO，交給不同類型的求解器去找。

    限制從哪來

    • 再生能源至少 20%、燃煤最多 30%、燃氣最多 50%行政院
    • 核能為 0台電

    [ PROBLEM ]

    八種電源，寫成一個 QUBO。

    每種電源的發電量編成位元，成本、碳排與限制都寫進同一個能量函數。四種求解器各自去找能量最低的那組位元，解回來就是一份發電配置。

    我們的做法：供需允許差 ±50 億度

    要求總發電量和需求完全相等太嚴：需求 2,524 億度時，各選一格又符合政策限制、總和剛好等於需求的組合只有 990 種，求解器很容易找不到合法解。我們允許兩者差在 ±50 億度以內，類似電網保留的備轉容量；再加一個偏差懲罰，差越多分數越差，把解拉回接近需求。合法的組合因此增加到 約 1,011 萬 種。

    [ MEASURE & ANNEAL ]

    量測之後，每個變數只剩 0 或 1。

    球面上的粒子塌縮到兩極，再排成 177 個位元。溫度高時位元一直翻轉，降溫後翻得越來越少，最後全部定住。

    2177≈1.92×1053

    種可能的配置，退火只停在其中一種。

    每種電源各選一格的配置只有 245 × 82 ≈ 5.1 億種（不含鬆弛變數），其他組合都違反「只選一格」，所以要靠懲罰項把它們的能量推高。

    [ DISPATCH ]

    定住的位元，就是一份發電配置。

    每種電源一列，每一格是一個發電等級，一列只會亮一格。位元解碼回每種電源的發電量；核能依現行政策設為零。

    每列的格數取自主實驗檔。

    [ SOLVERS ]

    同一個問題，四種找法。

    滑過或選取一列，預覽會播放那個求解器在能量地形上的搜尋方式。原理和模擬台的動畫相同。

    名稱類型說明

    [ ONE PROBLEM ]

    同一個問題，交給四種求解器。

    同一個情境、同一個能量函數，比較四種求解器找到的綜合目標 Hobj。

    綜合目標 Hobj，越低越好基準情境
